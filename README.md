Part 2 focuses on designing and improving the visual appearance of the Nyavhas M Poultry Farm website using CSS. 
An external CSS stylesheet was created and linked to the website's HTML pages. CSS was used to improve the website's colours, typography, spacing, navigation, product sections, forms, buttons and overall page layout. 
Responsive design was also implemented to ensure that the website can adapt to different screen sizes, including desktop computers, tablets and mobile phones. 
The website was tested using browser developer tools to identify and correct layout and responsive design issues.
The technologies Used that are I used for my part 2 are HTML5, Css3, visual studio code, GitHub and Microsoft Edge. 
 External CSS Stylesheet
An external CSS stylesheet called style.css was created in the css folder. 
The stylesheet is linked to the HTML pages using the following code: 
html <link rel="stylesheet" href="css/style.css">
